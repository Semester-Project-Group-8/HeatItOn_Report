\section{Abstract}

\hspace*{1cm} Manually planning all the heat schedules might be time-consuming and ineffiecient. However,  the heat production in the city of Heatington is currently managed that way, while securing the heat to around 1600 buildings. 

This project - HeatItOn, represents the development of a web application, providing an automated heat production platform. The project was developed using .NET C# and a MySQL database. API clients were used to provide communication between the backend and frontend. 

The frontend was developed using Avalonia, providing a user-friendly interface with separate tabs for scenario management, source data input, and results visualization. The application consists of several modules: an Asset Manager responsible for managing assets; 

a Source Data Manager responsible for processing incoming data; an Optimizer responsible for the main heat production optimization logic; a Result Data Manager responsible for processing output data; and a Data Visualization module responsible for presenting data through graphs and tables. 

The system enables users to input source data, select assets for optimization, and analyze the generated results through tables and graphical visualizations.
